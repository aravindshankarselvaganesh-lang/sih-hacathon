# 🧪 SULFSCAN Dosimeter AI Model Training Guide (1,000 Images)

This guide provides step-by-step instructions on training the AI colorimetry model using **1,000 real badge photos**.

---

## 📁 Directory Structure

```
ml_calibration/
├── dataset/                    # Pre-generated 1,000 synthetic baseline images
│   ├── images/                 # 1,000 synthetic badge PNGs
│   └── metadata.csv            # Auto-labeled ground truth (ppm, delta_e, status)
├── user_dataset/               # 👈 DROP YOUR 1000 REAL PHOTOS HERE
│   ├── images/                 # Put your badge photos (.png, .jpg) here
│   └── metadata.csv            # Labels generated by auto-labeler or manually
├── models/
│   └── dosimeter_model.json    # Trained AI model weights & metrics
├── generate_dataset.py         # Synthetic badge generator
├── auto_label_images.py        # Automatic badge color analyzer & CSV generator
└── train_model.py              # Self-contained ML training & evaluation engine
```

---

## 🚀 How to Train With Your 1,000 Photos (3 Simple Steps)

### Step 1: Copy Your 1,000 Photos
Copy all your badge images (.jpg, .jpeg, or .png) into:
```
ml_calibration/user_dataset/images/
```

### Step 2: Auto-Generate Labels (Zero Manual Data Entry)
Run the auto-labeler. It will scan all 1,000 images, locate the white reference patch, normalize ambient lighting, sample the reactive strip, and estimate initial $H_2S$ concentrations:
```bash
python ml_calibration/auto_label_images.py --img-dir ml_calibration/user_dataset/images
```
*This generates `ml_calibration/user_dataset/metadata.csv` automatically!*

*(Optional: You can open `metadata.csv` in Excel or VS Code to adjust actual ppm concentrations if you tested with known gas concentrations).*

### Step 3: Train the Model
Run the training engine on your dataset:
```bash
python ml_calibration/train_model.py --train --data-dir ml_calibration/user_dataset
```

## 🔍 Testing Single Image Predictions
You can test any image at any time via the command line:
```bash
python ml_calibration/train_model.py --predict path/to/badge.jpg --temp 30 --humidity 65
```
